這是什麼

本儲存庫是鐵板神數（又作鐵版神數、铁板神数 / Tieban Shenshu）的公開研究社群與教學示範專案。

鐵板神數是一套託名北宋邵雍的清代命理術數體系，以出生時間精確到「刻」的考刻推演著稱，按數取條、依條斷事。它是一份可供研究的傳統文化文獻，也是一段仍在被討論真偽與源流的歷史。

我們在這裡公開的是：

  • 鐵板神數入門知識、術語說明與研究資料索引
  • 獨立、可執行的教學工具（不依賴任何商業引擎）
  • 公開文獻的出處與引用方法
  • 少量有明確來源標註的公開示例

我們不在這裡公開：

  • 商業軟體的私有引擎、完整條文庫、完整考刻定分規則
  • 商業用戶端原始碼、安裝檔、授權與支付實作
  • 任何客戶姓名、生辰、命書或訂單資料

商業軟體與私有演算法不在此儲存庫公開。 完整功能請造訪官方網站。

快速開始（無需安裝）

本儲存庫自帶一個零依賴教學工具，用 Python 3.9+ 即可直接執行：

git clone https://github.com/tiebanshenshuapp/tiebanshenshu.git
cd tiebanshenshu/demo

# 1. 干支換算：西元年 → 干支
python tieban_open_tools.py ganzhi 1984

# 2. 六十甲子序號查詢
python tieban_open_tools.py jiazi 甲子

# 3. 傳統術語查詢（標註「傳統說法」與「學術討論」）
python tieban_open_tools.py term 考刻

# 4. 條文編號格式檢查（使用虛構樣例，無真實條文）
python tieban_open_tools.py check 4082

# 5. 文獻引用產生
python tieban_open_tools.py cite "皇極經世"

工具只在本地執行，不連網、不上傳、不需要生辰資料。詳見 demo/README.md。

研究方法：我們如何對待這份材料

本專案堅持三條：

1. 區分史料層級

層級 含義 我們的處理
古籍原文 清代及以前的刊本內容 引用並標註版本與來源
傳統說法 師傳、流派自述、民間傳聞 明確標註「傳統說法」，不當作史實
學術討論 可查證的文獻學研究 給出來源，容許多說並存
社群解釋 本專案的整理與說明 標明為編者觀點
虛構樣例 為示範格式而造的假資料 顯著標註為虛構

2. 不宣稱正統

歷史上關於鐵板神數的源流、作者、傳承存在明確爭議。明代楊慎已批評「今世游食術人妄造大定數、蠢子數託名康節」。我們不主張任何「唯一正宗」「帝王秘傳」「邵雍親傳」之說。

3. 不做命運斷言

本專案討論的是文獻與文化，不是預測服務。鐵板神數作為歷史術數文獻，不構成任何命運預測依據，請勿據以作出醫療、投資、法律或人生重大決定。
