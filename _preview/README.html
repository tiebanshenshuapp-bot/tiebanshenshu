这是什么

本仓库是铁板神数（又作铁版神数、鐵板神數 / Tieban Shenshu）的公开研究社区与教学演示项目。

铁板神数是一套托名北宋邵雍的清代命理术数体系，以出生时间精确到「刻」的考刻推演著称，按数取条、依条断事。它是一份可供研究的传统文化文献，也是一段仍在被讨论真伪与源流的历史。

我们在这里公开的是：

  • 铁板神数入门知识、术语说明与研究资料索引
  • 独立、可运行的教学工具（不依赖任何商业引擎）
  • 公开文献的出处与引用方法
  • 少量有明确来源标注的公开示例

我们不在这里公开：

  • 商业软件的私有引擎、完整条文库、完整考刻定分规则
  • 商业客户端源码、安装包、授权与支付实现
  • 任何客户姓名、生辰、命书或订单资料

商业软件与私有算法不在此仓库公开。 完整功能请访问官方网站。

快速开始（无需安装）

本仓库自带一个零依赖的教学工具，用 Python 3.9+ 即可直接运行：

git clone https://github.com/tiebanshenshuapp/tiebanshenshu.git
cd tiebanshenshu/demo

# 1. 干支换算：公历年 → 干支
python tieban_open_tools.py ganzhi 1984

# 2. 六十甲子序号查询
python tieban_open_tools.py jiazi 甲子

# 3. 传统术语查询（标注"传统说法"与"学术讨论"）
python tieban_open_tools.py term 考刻

# 4. 条文编号格式校验（使用虚构样例，无真实条文）
python tieban_open_tools.py check 4082

# 5. 文献引用生成
python tieban_open_tools.py cite "皇极经世"

工具只在本地运行，不联网、不上传、不需要生辰资料。详见 demo/README.md。

研究方法：我们如何对待这份材料

本项目坚持三条：

1. 区分史料层级

层级 含义 我们的处理
古籍原文 清代及以前的刊本内容 引用并标注版本与来源
传统说法 师传、流派自述、民间传闻 明确标注「传统说法」，不当作史实
学术讨论 可查证的文献学研究 给出出处，允许多说并存
社区解释 本项目的整理与说明 标明为编者观点
虚构样例 为演示格式而造的假数据 显著标注为虚构

2. 不宣称正统

历史上关于铁板神数的源流、作者、传承存在明确争议。明代杨慎已批评「今世游食术人妄造大定数、蠢子数托名康节」。我们不主张任何「唯一正宗」「帝王秘传」「邵雍亲传」之说。

3. 不做命运断言

本项目讨论的是文献与文化，不是预测服务。铁板神数作为历史术数文献，不构成任何命运预测依据，请勿据以作出医疗、投资、法律或人生重大决策。
