## 一、为什么单列这一页

铁板神数（鐵板神數）常被称为「皇極經世鐵版神數」，因为它的数理底座是邵雍的《皇极经世》。

研究这套体系时，会碰到两个**层次不同**的问题：

| 层次 | 是什么 | 开源状况 |
|---|---|---|
| **底层：皇極經世数理** | 元会运世、值卦推演、纪年换算 | ✅ **有 MIT 开源实现** |
| **上层：鐵版神數条文体系** | 起数、考刻定分、条文分类、命书组织 | ❌ 无可用的公开实现 |

本文分别说明。

## 四、关于商业在线服务

市面上存在若干提供「在线鐵版神數免费算命」的商业网站。

**我们对这类系统的调研结论（事实层面）：**

1. 这类系统绝大多数是**服务端实现**（如 ASP.NET / PHP），算法在服务器上，客户端不可见
2. GitHub 上**不存在**这些系统的公开源码
3. 这些网站的条文与命书内容通常**受其自身版权声明保护**

**因此我们的立场：**

| 做法 | 我们的态度 |
|---|---|
| 观察其页面提供了哪些功能字段 | ✅ 合法（公开信息的功能观察） |
| 学习其**分类思路**（如按主题分类输出） | ✅ 合法（思想不受版权保护） |
| 复制其条文内容 | ❌ **不做**，侵权 |
| 复制其页面代码 | ❌ **不做** |
| 反向获取其服务端算法 | ❌ **做不到**（不在客户端） |

> 我们**不会**把任何第三方商业系统的内容搬进本仓库。
> 本仓库所有条文示例都必须是**自有底本**或**明确公版**，且经权利审核。

## 五、那我们要怎么做一个「能排盘出命数」的教学工具？

如果目标是做一个**面向公众的免费排盘演示**，合法路径只有一条：

```
1. 底层数理
   └─ 用 MIT 许可的皇極經世实现（如 Ryanlyly-ai/huangji-jingshi）
      或自行实现元会运世（公版知识）

2. 四柱排盘
   └─ 自行实现（节气表、真太阳时经度校正、早子/晚子换日）
      这些是公开的天文与历法知识

3. 起数算法
   └─ 从公版文献自行推演
      各派不同，不存在唯一标准 —— 这正是要如实说明的

4. 条文
   └─ 必须来自自有底本，且经权利审核
      未审核前，宁可不放（当前是 0 条）

5. 输出结构
   └─ 分类思路可自行设计（如按主题的「爻」分类）
      但不得复制任何现成系统的条文文字
```

**关键原则：**

> **算法可以学，结构可以参考，条文必须自有。**
