# assets/

本目录存放品牌与视觉资源。

## brand/
品牌标识、配色规范、字体说明。

## screenshots/
软件界面截图。**所有截图必须经过脱敏**，不得包含：
真实客户姓名、出生资料、订单信息、完整命书、完整条文、授权码、
服务器内部路径、调试日志、账号、私有算法。

未正式发行的功能必须标注「研发预览」。

## social-preview/
GitHub 社交分享封面（建议 1280×640）。

## 当前状态

⚠️ 本目录目前**为空**。

原因：品牌素材与脱敏截图需经 OWNER 授权后方可使用。
在获得授权前，我们不使用任何图片来源不明的图片。

详见 [CONTRIBUTING.md](../CONTRIBUTING.md) 与施工图纸第 19 章。
