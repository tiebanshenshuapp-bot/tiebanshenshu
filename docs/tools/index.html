在线教学工具

全部在您的浏览器本地运行。不需要安装、不需要注册、不上传任何数据、不询问真实姓名或生辰。 计算结果仅供参考与学习，不构成任何命运预测依据。
① 公历年 → 干支 ② 六十甲子 ③ 术语查询 ④ 编号格式校验 ⑤ 文献引用 ⑥ 繁简对照 ⑦ 干支关系

① 公历年 → 干支

按公元 4 年为甲子年的通用算法换算。

⚠️ 命理上排年柱应以立春为界。例如 1984 年 1 月出生者，命理年柱仍属 1983 年（癸亥）。 本工具按公历年份直接换算，请自行注意此边界。

② 六十甲子查询

查看完整六十甲子表

③ 传统术语查询

每条标注证据层级：古籍原文 / 传统说法 / 学术讨论 / 编者观点。

④ 条文编号格式校验

只校验编号格式（是否落在公开讨论的区间内），不返回任何条文内容。

默认区间 1001–13000 仅为演示参数，不代表任何特定抄本的权威映射。 不同传本的分集方式与编号范围存在差异。

⑤ 文献引用生成

⚠️ 引用公版古籍必须注明你实际使用的版本。不同版本条文文字互有出入。

⑥ 繁简对照

仅做逐字对照提示，不是完整转换引擎。正式转换请使用 OpenCC。

⑦ 干支关系查询

天干五合、地支六冲、六合、三合。支持输入完整干支（如「甲子」）或单字（天干/地支自动识别）。

关于这些工具

工具能做什么不能做什么
① 年份干支公历年 → 干支、五行不判断立春分界
② 六十甲子干支 ⇄ 序号双向查询不推断吉凶
③ 术语查询释义 + 证据层级 + 来源不给个人命运结论
④ 编号校验格式是否合法、集次位置不返回条文内容
⑤ 引用生成引用骨架 + 补全提醒不替你查版本
⑥ 繁简对照逐字差异提示非完整转换引擎
⑦ 干支关系五合 / 六冲 / 六合 / 三合不论命局喜忌，不做完整合盘

命令行版本

同样功能的 Python 版本在 demo/ 目录，零依赖，可离线运行：

git clone https://github.com/tiebanshenshuapp-bot/tiebanshenshu.git
cd tiebanshenshu/demo
python tieban_open_tools.py ganzhi 1984
python tieban_open_tools.py jiazi 甲子
python tieban_open_tools.py term 考刻

网页版与 Python 版使用同一套规则与数据，结果一致。
