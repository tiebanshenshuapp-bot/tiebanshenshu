# 考刻定分是什麼？

> 鐵板神數有一套「按數取條」的體系，但**真正讓它區別於其他術數的，是考刻定分**。
> 這一頁講清楚它是什麼、為什麼存在、以及邊界在哪。

---

## 一、先説兩個詞

### 刻

中國傳統把一天分為十二個時辰，每個時辰 = 2 小時。

鐵板神數在此基礎上進一步細分：

```
一個時辰（2 小時）
        ↓ 分為八刻
一刻 = 15 分鐘
        ↓ 每刻再分十五分
一分 = 1 分鐘
```

所以一個時辰 = 八刻 = 一百二十分鐘。

> **證據層級：古籍原文層面**。把時辰細分為刻，傳統曆法與命理文獻中普遍存在。
> 但「一刻 15 分鐘、一時辰八刻」這一具體劃分，各文獻表述未必完全一致。

### 定分

在已經確定的「刻」之內，再細分為「分」，進一步鎖定出生時刻。

「考刻」+「定分」合稱 **考刻定分**。

---

## 二、為什麼要考刻？

核心矛盾是一個**物理事實**：

> 同一時辰（2 小時內）出生的人，按傳統四柱排盤，**八字完全相同**。

古代一個時辰裏出生的嬰兒可能有很多。他們的八字一樣，但人生並不一樣。

傳統上的解釋是：

1. 時辰太粗（2 小時），必須細分才有區分度
2. 細分之後，不同刻分對應不同條文
3. 但出生時間往往記不準（過去沒有精確計時）

**於是產生了「考刻」這個做法**：不問時鐘，問人生事實。

---

## 三、傳統上怎麼考

### 基本思路

```
先按已知出生時間起數 → 得到一個候選刻分範圍
              ↓
詢問若干「人生事實」（主要是六親信息）
              ↓
在候選範圍內，找出與這些事實相符的刻分
              ↓
確定「真刻」→ 取條文
```

### 傳統上常用的校驗錨點

| 類別 | 典型問法 | 性質 |
|---|---|---|
| 父母 | 父親屬什麼？母親屬什麼？ | 硬錨點（可精確核對） |
| 兄弟 | 有幾個兄弟姐妹？排行第幾？ | 硬錨點 |
| 配偶 | 配偶哪年生？屬什麼？ | 硬錨點 |
| 子女 | 有幾個孩子？幾男幾女？ | 硬錨點 |
| 性情 | 性格如何？ | 軟錨點（主觀） |
| 事業 | 從事什麼行業？ | 軟錨點 |

**傳統上認為硬錨點更可靠**，因為生肖、人數是可以精確核對的事實，而性格描述彈性較大。

> **證據層級：傳統説法**。以上流程是各派共通的**框架性描述**。
> 但「用哪些錨點、如何對應、候選如何排序」各家不同，**不存在唯一公定標準**。

## 四、這一環節的爭議（必須説清楚）

考刻定分是鐵板神數最獨特的地方，也是**最受質疑的地方**。

### 批評方的觀點

> 「你先問我父親屬什麼，再告訴我條文説我父親屬什麼。這叫預測嗎？」

這個批評**在方法論上是成立的**：

```
如果刻分是「用已知事實調出來的」
   → 那麼條文與這些事實相符，是必然的，不是預言的
```

用統計學的語言：這是**用過擬合的方式提高擬合度**。

### 支持方的回應

傳統上的説法是：

1. 刻分不是"隨便調"，是在**有限的候選範圍**內定位
2. 定位之後，條文是**整體輸出**的，不是逐條定製的
3. 真正的檢驗在於：**定位之後，那些沒有被問到的條文，是否也應驗**

**這個回應在邏輯上也説得通** —— 如果考刻只用了「父母生肖」，
但定位後輸出的條文還準確描述了「婚姻狀況」（沒被問過），那確實有信息量。

### 我們的立場

> 我們不站隊，但要提醒：**判斷一個系統的準確性時，必須區分「考刻之前」和「考刻之後」。**

詳見 [準唔準：一個誠實的分析](accuracy.md)。

## 五、為什麼各流派説法不一致

如果你去查不同來源，會發現：

| 問題 | 不同來源的回答 |
|---|---|
| 一個時辰分幾刻 | 多數説八刻，也有其他説法 |
| 一刻多少分鐘 | 多數説 15 分鐘 |
| 用什麼錨點考刻 | 各派不同 |
| 刻與條文如何對應 | **各家師傳，説法不一** |
| 是否需要真太陽時 | 有的要求，有的不要求 |

### 原因

1. **傳承方式**：這套東西長期是**師傳**，沒有統一教材
2. **文獻缺失**：原始文獻缺乏，各本抄錄有差異
3. **後人增補**：不同時代的人做了不同補充
4. **商業保密**：部分從業者有意不公開細節

**結論**：所謂「鐵板神數標準算法」**並不存在一個公認版本**。

> 任何聲稱「我這才是唯一正統」的説法，都需要證據支撐。我們沒見過這樣的證據。

## 六、我們能公開什麼，不能公開什麼

這一節很重要，請讀完。

### ✅ 可以公開（本頁已公開）

- 刻、分的基本定義
- 為什麼要考刻（物理層面的原因）
- 考刻的一般流程框架
- 常用錨點的**類別**
- 各派不一致這一**事實**
- 方法論上的批評與回應

### ❌ 不在公開範圍

| 內容 | 原因 |
|---|---|
| 具體的六親—刻分對應表 | 屬各家師傳 / 商業實現，公開會造成誤導（因為沒有唯一標準） |
| 起數配值表 | 同上 |
| 刻分到條文號的完整映射 | 屬商業私有實現 |
| 具體條文的完整文本 | 屬私有資產（當前公開示例：0 條） |

### 為什麼這樣劃界

不是「藏着掖着」，而是**兩方面原因**：

**原因一：沒有唯一正確答案**

如果公開一份「對應表」，會讓人以為這是標準答案。
但實際上各派不同，公開一份反而**製造了新的誤導**。

**原因二：商業邊界**

我們如實説明：這些是商業產品的核心，不在公開範圍。
你可以不同意這個邊界，但至少我們**明確告訴你邊界在哪**，
而不是含糊其辭。

## 八、一句話總結

> **考刻定分**要解決的，是「同一個時辰出生的人八字一樣」這個物理問題。
> 它的傳統做法是用已知事實反推真刻。
> 這個做法**在方法論上有爭議**，但爭議本身值得研究。
> 具體的對應表**不在公開範圍**，因為各派不同、且屬商業實現。
