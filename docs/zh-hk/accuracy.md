# 鐵板神數準唔準？

> 這是本站被問得最多的問題。
> 我們不會告訴你「很準」，也不會告訴你「沒用」——**因為這兩個答案都不誠實**。

---

## 一、先説結論

| 問題 | 誠實的回答 |
|---|---|
| 有沒有科學證據證明它準？ | **沒有**。目前沒有任何通過同行評議的、可復現的驗證研究 |
| 那為什麼很多人説很準？ | 有幾個**可解釋的原因**，下文逐一分析 |
| 那它是真是假？ | 作為**文化現象**是真的；作為**預測工具**無法驗證 |
| 那我該不該信？ | 你可以把它當作一面鏡子，但**不要拿它做重大決定** |

## 二、為什麼「準不準」這麼難驗證

這不是玄學問題，是**方法論問題**。任何預測系統要驗證準確性，必須滿足三個條件：

### 條件 1：事前説出，而不是事後解釋

```
❌ 不算驗證：
   「你今年是不是工作有變動？」（對方説"是"）→「看，準吧」
   ↑ 這是釣魚式提問，不是預測

✅ 算驗證：
   2026 年 1 月 1 日，書面寫下：
   「此人 2026 年 3 月會有工作變動」
   封存 → 2026 年 12 月打開核對
```

**關鍵問題**：如果一個系統只在**得知結果之後**才顯得準，那它在事前就沒有預測力。

### 條件 2：必須有明確的失敗記錄

任何真實有效的預測方法，都會有**失敗案例**。

如果一個體系裏：
- 只流傳成功案例
- 失敗的案例從不被提起
- 或者失敗時歸因於「你心不誠」「你時辰報錯了」

那麼這個體系**無法被檢驗**，也就無法被證實。

### 條件 3：對照組

如果要證明"鐵板神數比隨機更好"，需要：

```
實驗組：用真實出生時間算出條文
對照組：用隨機生成的條文
        ↓
讓第三方（不知道分組）判斷哪組更符合當事人的實際情況
        ↓
如果兩組判斷結果沒有顯著差異 → 説明「準」來自心理效應
```

**據我們所知，目前沒有任何公開發表的這類雙盲研究。**

## 三、那為什麼很多人覺得「真的很準」？

這不是騙人，是**心理學上有明確解釋的現象**。至少有五個原因：

### 原因 1：巴納姆效應（Barnum Effect）

人們傾向於認為**模糊而普遍的描述**準確描述了自己。

> 「你有才華但有時不被理解」
> 「你外表堅強，內心其實敏感」
> 「你年輕時經歷過一次較大的挫折」

這類話對**絕大多數人**都成立。實驗證明，即使告訴受試者這是"專門為你生成的性格分析"，
實際上所有人拿到的是**同一份**，仍有超過 80% 的人認為"相當準確"。

### 原因 2：確認偏誤（Confirmation Bias）

人腦會**自動記住符合的，自動忽略不符合的**。

一條命書 20 句，19 句不準、1 句特別準 —— 大多數人會記住那 1 句。

### 原因 3：考刻的事後擬合

這是鐵板神數特有的問題，也是**最需要警惕的一點**。

考刻的流程是：先按出生時間起數 → 再問「你父親屬什麼」「你有幾個兄弟姐妹」→
用這些信息**反過來調整**刻分。

**問題在於**：如果你調整刻分時用的是"已知事實"，那麼最後得出的條文與這些事實相符，
是**必然的**，不是預測出來的。

```
這就像：
  先問「你今年多大了」
  再填「你的出生年份」
  然後宣佈「我算出了你的年齡，真準」
```

> ⚠️ **這不是説考刻本身是騙術**。傳統上考刻的目的確實是"定真刻"。
> 但要理解：**考刻之後的準，和考刻之前的準，意義完全不同。**

> 關於考刻為何最受質疑，見 [考刻定分詳解](kaoke.md)。

### 原因 4：選擇性記憶 + 社交傳播

人們傾向於：
- 在社交場合分享"應驗"的故事
- 不分享"沒應驗"的經歷（因為沒面子）
- 聽者只聽到成功案例

久而久之，一個圈子裏會形成"這個很準"的集體印象，
但這個印象的**樣本是被人為篩選過的**。

### 原因 5：模糊語言允許自我解釋

好的斷語往往寫得**既可這樣理解，也可那樣理解**：

> 「早年辛勞，中年漸入佳境」

- 如果當事人中年確實好轉 → 「太準了」
- 如果中年也沒好轉 → 「説的是'漸'，還沒到」

**任何結果都能被解釋為符合。**

## 四、那這套東西還有價值嗎？

**有，但不是「預測價值」。**

| 價值類型 | 是否存在 | 説明 |
|---|---|---|
| 預測未來 | ❌ 無法驗證 | 沒有可復現證據 |
| 認識自己 | ⚠️ 有限 | 作為一種提問框架，能促使人反思 |
| 文化研究 | ✅ 確有 | 反映清代社會對命運、家族、倫理的想象 |
| 文學價值 | ✅ 確有 | 條文本身是韻文，有文學性 |
| 心理安慰 | ✅ 確有 | 在焦慮時提供敍事框架（但這也是風險） |
| 社交話題 | ✅ 確有 | 一種社交貨幣 |

**最重要的區別**：

> 把鐵板神數當**鏡子**用 → 它在問你「你怎麼看自己的人生」
> 把鐵板神數當**説明書**用 → 它在告訴你「你只能這樣活」

前者無害，後者危險。

## 五、你自己怎麼判斷一套結果可不可信

給你一份**可操作的檢查清單**。不管是誰給你算的，都可以這樣查。

### 檢查 1：有沒有事前聲明？

| 情況 | 可信度 |
|---|---|
| 事前書面寫下具體預測，事後核對 | ⭐⭐⭐⭐ 可討論 |
| 只做事後解釋 | ⭐ 無驗證價值 |
| 拒絕寫下具體預測 | ⭐ 需要警惕 |

### 檢查 2：有沒有承認不確定？

好的從業者會説：
- 「這一條我不確定」
- 「不同版本這裏寫法不同」
- 「這屬於傳統説法，沒有史料依據」

如果一個從業者**什麼都能答、什麼都肯定**，反而要小心。

### 檢查 3：有沒有製造恐懼？

**這是最重要的紅線。**

| 話術 | 判斷 |
|---|---|
| 「你今年有大災，必須化解」 | 🚩 高危 |
| 「不做法事會克家人」 | 🚩 高危 |
| 「你命裏有大劫，只有我能解」 | 🚩🚩 典型詐騙 |
| 「這個説法我不確定，你可以自己判斷」 | ✅ 正常 |

**任何以恐懼為手段促成付費的，都不是在研究命理，是在做詐騙。**

### 檢查 4：收費是否與"化解"掛鈎？

| 模式 | 判斷 |
|---|---|
| 一次性諮詢費，內容就是分析 | ✅ 正常商業行為 |
| 先免費算，説你有災，再收高價化解 | 🚩 詐騙模式 |
| 按"化解難度"階梯收費 | 🚩🚩 詐騙 |
| 保證「做了就轉運」 | 🚩🚩🚩 直接報警 |

### 檢查 5：能不能説清「它是怎麼算出來的」？

不需要公開全部算法，但應該能説明：
- 起數的基本邏輯
- 考刻依據哪些信息
- 條文的出處版本

如果對方説「這是天機不可泄露」——**天機不可泄露的通常不是天機，是商業機密。**

## 六、我們自己的立場

既然你看到這一頁，我們也把話説透：

**我們做這個項目，不指望你相信鐵板神數。**

我們做的是：
- 把術語講清楚（讓你知道別人在説什麼）
- 把源流講清楚（哪些有史料、哪些是傳説）
- 提供能自己驗證的工具（干支、甲子、編號格式）
- **明確告訴你這套東西的邊界在哪**

**如果你最終決定不付費**——那也完全正常。
我們的公開文檔和工具會一直免費。

**如果你決定付費**——請確認你買的是：
- 一份**文化體驗** ✅
- 或者一份**自我反思的框架** ✅
- **而不是**「改變命運的技術」❌

## 七、一句話總結

> **鐵板神數準唔準？**
> 作為文獻，它是真的。
> 作為預測，它無法被證明。
> 作為鏡子，它能幫你想清楚一些事。
> 作為説明書，它會限制你。

**別讓它替你做決定。**
