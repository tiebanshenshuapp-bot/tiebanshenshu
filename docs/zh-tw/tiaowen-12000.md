# 鐵板神數「12000 條」是什麼

搜「鐵板神數12000條」的人通常想知道三件事：

1. 這個數字是真的嗎？
2. 一萬二千條條文具體是什麼？
3. 為什麼有的地方說 12,000，有的說別的數？

本文只講**條目的組織方式與數目來歷**，**不列任何條文原文**。

---

## 一、先說結論

**「一萬二千條」是傳統通稱，不是精確常數。**

| 說法 | 性質 |
|---|---|
| 「約一萬二千條」 | 傳統通稱，指條文規模量級 |
| 具體條數 | **隨底本、版本、整理方式而變** |
| 「條條都能對上某個人」 | 不成立。條文是按數取條的**語料池** |

看到不同來源給出不同數字（11,949／12,000／12,046／25,000+），
**不一定是造假，多半是底本不同**。

---

## 二、條文是什麼

鐵板神數的產出不是「分析」，而是**編號的斷語文字**。

```
編號  →  文字（古譜原文）  →  可能的年齡標註  →  來源版本
```

所以「12000 條」= **語料池裡編號條目的數量量級**。

它不是：
- 12000 種命
- 12000 句萬能斷語
- 能窮盡所有人的 12000 個答案

---

## 三、編號是怎麼來的

傳統做法：由出生時間推演出**起數**，再按**刻**與**分**在數字空間裡定位，
最後對映到條文編號。

| 環節 | 對編號的影響 |
|---|---|
| 真太陽時校正 | 若錯誤，時辰錯，起數錯，編號全錯 |
| 考刻定分 | 刻分不同 → 同一人可能取到不同編號 |
| 版本對映表 | 不同底本的編號空間不同 |

**所以編號不是身份證號，是「按當前刻分與所用底本查出來的位置」。**

---

## 四、為什麼不同版本條數不同

| 差異來源 | 表現 |
|---|---|
| 底本不同（清刊／民國石印／現代轉錄） | 條目數、字句不同 |
| 是否含「起推說明」類條目 | 部分底本把排盤說明也佔編號，條數虛高 |
| 是否合併重複條目 | 有的整理者合併，有的保留 |
| 繁簡與標點處理 | 同一條在不同整理下文字不同 |
| 是否收錄旁證／附錄 | 有的版本把校勘附錄計入總數 |

**本倉自己的實測**（僅陳述事實，不作判定）：
在公開可得的語料中，同一條編號在兩個不同來源之間，
歸一到同一字形後，仍有相當比例內容不一致。
這說明**編號空間不可跨版本混用**。

> 具體比例與技術細節見 [研究方法](research-methods.html)。
> 此處不列條文，也不評價哪一版「正確」。

## 五、對使用者的實際意義

### 如果你在研究
- 必須先確定**用哪一版底本**，否則編號無法對照
- 引用時要標**版本 + 編號**，不能只給編號
- 不要跨版本拼條文，會拼出錯的結果

### 如果你在使用軟體
- 同一套軟體內部編號是自洽的
- 換版本後，歷史命書應保留原版本，不能靜默改編號
- 這正是正規產品要保留歷史快照的原因

### 如果你在判斷一個說法可不可信
看它有沒有交代：用的哪一版底本、條數是多少怎麼數的、編號空間如何定義。

**只說「一萬二千條」但不說版本的，都不足以作為研究依據。**

---

## 六、常見誤解

**誤解 1：12000 條 = 12000 個命格**
不是。條文是斷語文字池，不是命格分類表。

**誤解 2：條數越多越正統**
不成立。條數差異多來自整理口徑，與權威性無必然關係。

**誤解 3：可以按編號在網上搜到「我那條」**
編號脫離**刻分 + 版本**就沒有意義。單獨一個編號無法對應到具體個人。

**誤解 4：有「鐵板神數12000條全文下載」就是拿到了核心**
公開流傳的條文摘錄多為部分轉錄，且缺版本資訊；即便拿到全文，
**沒有考刻定分也無法定位到個人**。

---

## 七、證據分層

| 說法 | 層級 |
|---|---|
| 「一萬二千條」是傳統通稱 | 可考（多份公開文獻一致使用該量級） |
| 條數隨底本／整理方式變化 | 可考（實測不同來源條數不同） |
| 編號需刻分 + 版本才有意義 | 傳統流傳 + 邏輯必然 |
| 跨版本編號不可混用 | **本倉實測** |
| 具體哪一版最權威 | **學術爭議，本倉不裁決** |
