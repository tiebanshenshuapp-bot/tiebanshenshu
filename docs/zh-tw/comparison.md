# 鐵板神數 vs 八字 vs 紫微斗數

> 這三個是中文命理圈最常被提到的體系。
> 它們**不是同一套東西**，混著用會得出錯誤結論。

---

## 一、先看一張總表

| 維度 | **八字（子平術）** | **紫微斗數** | **鐵板神數** |
|---|---|---|---|
| 輸入 | 四柱八字 | 四柱 → 安星盤 | 四柱 → 起數 |
| 核心中間產物 | 十神、格局 | 十二宮 + 百餘星曜 | 條文編號 |
| 主要分析方式 | 論旺衰、取用神 | 看星曜落宮與四化 | 查條文斷語 |
| 輸出形態 | 論述性的文字分析 | 星盤 + 宮位解讀 | **固定編號的韻文斷語** |
| 關鍵難點 | 用神取法（分歧最大） | 星曜組合與四化判斷 | **考刻定分** |
| 學習門檻 | 中（理論體系龐大） | 中偏高（星曜繁多） | 偏高（依賴師傳 + 條文） |
| 是否依賴師傳 | 相對少，公開文獻充足 | 相對少，體系公開 | **強依賴**（對應表各家不同） |
| 可自我學習 | 較可行 | 較可行 | **較困難** |

> 證據層級：**學術討論**。以上是各體系的通行描述，具體細節各派有別。

## 二、三者到底在做什麼

### 八字（子平術）：分析命局結構

```
四柱 → 找日主強弱 → 定格局 → 取用神 → 論大運流年
```

**本質**：一套**結構分析**方法。
它回答的是「這個命局的結構是怎樣的，什麼五行對它有利/不利」。

**輸出**：論述。同一張八字，不同命理師可能給出不同結論（因為用神取法有分歧）。

### 紫微斗數：星系落宮

```
四柱 → 定命宮身宮 → 安十二宮 → 布星曜 → 看四化飛星
```

**本質**：一套**星盤象徵**體系。
它回答的是「哪些象徵性星曜落在哪些生活領域」。

**輸出**：星盤 + 逐宮解讀。視覺上最直觀（有圖）。

### 鐵板神數：按數取條

```
四柱 → 起數 → 考刻定分 → 取條文編號 → 查條文
```

**本質**：一套**編號索引**體系。
它回答的是「這個命對應的編號是哪些，條文說了什麼」。

**輸出**：編號化的韻文斷語。**不是分析過程，是直接給結論**。

## 三、最大的區別：有沒有「中間推理」

這是理解三者差異的關鍵。

```
八字：
  四柱 → （十神/格局/用神）→ 結論
         ↑ 這裡有一整套推理過程，可討論、可質疑

紫微：
  四柱 → （宮位/星曜/四化）→ 結論
         ↑ 同樣有推理過程，可討論

鐵板神數：
  四柱 → （起數 → 條文號）→ 條文原文
         ↑ 這一段是「查表」，不是推理
```

**意味著什麼**：

- 八字的結論**可以爭論**（「你這個用神取錯了」）
- 鐵板神數的條文**不能爭論**（它就是這麼寫的，你要麼接受要麼不接受）

**這是根本性的方法論差異**，不是優劣之分。

## 四、能不能互相解釋？（重要）

### 常見錯誤做法

```
❌ 用八字的「七殺格」去解釋鐵板神數的一條條文
❌ 用紫微的「命宮七殺」去推斷鐵板神數會出哪條
❌ 把三者的結論混在一起"綜合判斷"
```

**為什麼錯**：

三者的**中間產物完全不同**，不存在對映關係。
硬要對應，只會得到自己想看到的結果（確認偏誤）。

### 正確做法

```
✅ 分別用三套體系算，然後**分開看**
✅ 如果三者結論一致 → 值得注意（但也不代表正確）
✅ 如果不一致 → 說明至少有一個體系在這個命上"說不通"
```

### 我們明確的立場

> **用八字理論解釋鐵板神數，方向是錯的。**
> 這是 [入門總覽](index.md) 裡已經寫明的一條。

## 五、哪個更準？

這是所有人最想問的。

**誠實回答：三個都無法被驗證。**

| 體系 | 有科學證據嗎 | 能否設計對照實驗 |
|---|---|---|
| 八字 | 無 | 理論上可以，實際幾乎沒人做 |
| 紫微斗數 | 無 | 同上 |
| 鐵板神數 | 無 | 更難（考刻會用到已知事實） |

### 為什麼"哪個更準"這個問題本身有問題

因為**沒有統一的評判標準**：

- 怎麼算"準"？一件大事對算準，還是十件小事對算準？
- 誰來判斷"準"？當事人？第三方？
- 事後多久判斷？一個月？一年？

**沒有標準，就無法比較。**

如果有人告訴你「鐵板神數比八字準三倍」，請追問：
**這個"三倍"是怎麼測出來的？樣本多少？誰評估的？**

詳見 [準不準：一個誠實的分析](accuracy.md)。

## 六、那為什麼會有這麼多體系

這是一個**文化史**問題，比"哪個準"更有意思。

### 原因 1：不同的切入角度

- 八字：從**五行生剋**切入
- 紫微：從**星象象徵**切入
- 鐵板：從**數字索引**切入

古人對同一個問題（如何看待命運）嘗試了不同路徑。

### 原因 2：不同時代的技術條件

- 八字成熟於唐宋（干支曆法發達）
- 紫微傳說源於宋（星象學影響）
- 鐵板興起於清代（印刷術普及使條文彙編成為可能）

### 原因 3：不同的社會需求

- 八字 → 適合**論述**（可以講得很細，適合諮詢）
- 紫微 → 適合**圖示**（直觀，適合教學）
- 鐵板 → 適合**權威斷言**（"鐵板釘釘"，適合建立權威感）

**"鐵板釘釘"這個成語本身就是賣點** —— 它暗示不容置疑。

這也是為什麼鐵板神數特別容易被用於**高壓推銷**（"你命裡就是這樣，必須化解"）。

## 七、我該學哪個 / 用哪個

| 你的目的 | 建議 |
|---|---|
| 想理解命理的理論結構 | 從**八字**入手（文獻最全、邏輯最清楚） |
| 喜歡圖示化、視覺化 | **紫微斗數**（星盤直觀） |
| 對"確定性斷言"感興趣 | 鐵板神數（但要警惕被利用） |
| 純做文化研究 | 三個都看，比較它們的**方法論差異** |
| 想找答案解決人生困惑 | **一個都別指望**（見下文） |

### 一句提醒

> 學這三套東西，最大的收穫不是"能算準"，
> 而是**看穿別人是怎麼用它們說服你的**。
>
> 知道「考刻是用已知事實反推」之後，
> 你就不會輕易被"我算出了你父親屬什麼"震住。

## 八、常見混淆清單

| 混淆說法 | 事實 |
|---|---|
| 「鐵板神數就是八字」 | ❌ 不同體系，中間產物與輸出形態都不同 |
| 「紫微比八字高階」 | ❌ 沒有可比性，切入角度不同 |
| 「鐵板神數包含紫微」 | ❌ 各家體系獨立，無包含關係 |
| 「學會八字就能看鐵板」 | ❌ 鐵板的核心是起數+條文，八字不涉及 |
| 「三種都會，可以互相印證」 | ⚠️ 可以分別看，但不能用一套解釋另一套 |
| 「鐵板神數是八字的高階版」 | ❌ 無史料支援這種說法 |

---

## 九、一句話總結

> **八字是結構分析，紫微是星象象徵，鐵板是編號索引。**
> 三者切入角度、中間產物、輸出形態全部不同，**不能互相解釋**。
> 至於哪個更準 —— **三個都無法驗證，這個問題本身缺少評判標準。**
> 真正有價值的收穫，是理解它們各自怎麼"說服"人。
