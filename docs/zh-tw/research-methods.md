# 研究方法

> 本文說明本項目**如何判斷、如何引用、如何處理爭議**。

---

## 一、核心原則：三條硬規矩

### 規矩 1：區分史料層級

| 層級 | 判據 | 處理方式 |
|---|---|---|
| **古籍原文** | 能在清代及以前刊本中查到 | 引用並註版本、卷次、頁碼 |
| **傳統說法** | 師傳、流派自述、民間傳聞 | 明確標註，**不得表述為史實** |
| **學術討論** | 有文獻學研究支持 | 給出來源，**容許多說並存** |
| **編者觀點** | 本項目的整理、推論 | 標明是本項目觀點 |
| **虛構樣例** | 為示範格式而造 | **顯著標註「虛構」** |

**為甚麼這條最重要？**

因為術數研究最大的問題不是「說錯」，而是**把「聽說」當成「記載」**。

---

### 規矩 2：不宣稱正統

| 禁止表述 | 原因 |
|---|---|
| 「唯一正宗」 | 傳承譜系缺失，無人能證明 |
| 「邵雍親傳」 | 明代已被楊慎質疑 |
| 「帝王秘傳」 | 無任何史料 |
| 「香港是真正發源地」 | 香港是傳播重鎮，非起源地 |
| 「我們的算法最準確」 | 無法用可重現方法驗證 |

---

### 規矩 3：不做命運斷言

本項目討論**文獻與文化**，不提供預測服務。

禁止：「你的命如何」、「準確率 XX%」、「改命」、「轉運」，以及任何醫療、投資、法律建議。

---

## 二、引用規範

### 公版古籍的引用格式

```
作者. 書名[M]. 朝代. 版本資料. 卷次: 頁碼.

示例：
邵雍. 皇極經世[M]. 宋. 清乾隆XX年刊本(或：XX出版社19XX年影印本). 卷X: 第XX頁.
```

**硬要求**：

1. **必須寫版本** —— 「據古籍記載」不算引用
2. **盡量寫頁碼**
3. **區分原文與轉引**

## 三、如何處理爭議

我們**不選邊，而是呈現爭議結構**。

### 何時我們會選邊

只有當證據明顯不對等時：

| 爭議 | 我們的立場 | 理由 |
|---|---|---|
| 是否邵雍所作 | 傾向「不是」 | 宋代無記載 + 明代已有明確批評 |
| 「鐵卜子」是否真有其人 | 傾向存疑 | 同時代文獻完全無痕跡 |
| 各本條文哪本更可靠 | **不判斷** | 缺乏校勘研究 |
| 一萬二千條的確切數目 | **不判斷** | 各本不同 |

## 五、我們不做甚麼研究

| 不做的 | 原因 |
|---|---|
| 用統計方法「驗證」準確性 | 涉及大量個人資料，方法論上難以設對照 |
| 為商業產品做效果背書 | 利益衝突 |
| 收集用戶生辰做「研究」 | 私隱風險 |
| 建立個人命例資料庫 | 即使匿名化風險仍高 |
| 評價其他流派的「真假」 | 超出能力範圍 |

## 六、如何評價我們的可信度

### 檢查 1：看有沒有層級標註
通篇不區分「史實」與「傳說」，**可信度就低**。

### 檢查 2：看有沒有版本資料
引用古籍卻不寫版本，說明作者可能**未見過原書**。

### 檢查 3：看有沒有承認不確定
好的研究會明確說「這一點不清楚」。甚麼都斬釘截鐵，**反而可疑**。

### 檢查 4：看工具有沒有可重現性
本項目的工具你可以自己跑、自己改、自己驗證。

### 檢查 5：看我們對批評的反應
如果你指出我們的錯誤，我們**改了**，說明這個項目是認真的。

**歡迎你來檢驗第 5 條。**
