# Tieban Shenshu vs BaZi vs Zi Wei Dou Shu

> These three are the most frequently mentioned systems in Chinese astrology.
> They are **not the same thing**, and mixing them produces wrong conclusions.

---

## 1. Overview table

| Dimension | **BaZi (Four Pillars)** | **Zi Wei Dou Shu** | **Tieban Shenshu** |
|---|---|---|---|
| Input | Four pillars | Four pillars → star chart | Four pillars → number derivation |
| Core intermediate | Ten Gods, chart patterns | 12 palaces + ~100 stars | Verse ID |
| Analysis mode | Assess strength, choose useful god | Read star placements and transformations | Look up verses |
| Output form | Discursive analysis | Chart + palace readings | **Fixed, numbered verses** |
| Hardest step | Choosing the useful god (most disputed) | Star combinations and transformations | **Kaoke / dingfen** |
| Learning curve | Moderate (large theory body) | Moderate-high (many stars) | High (depends on transmission + corpus) |
| Depends on lineage? | Relatively little; open literature | Relatively little; public system | **Strongly** (tables differ by school) |
| Self-study feasible? | Fairly | Fairly | **Difficult** |

> Evidence level: **scholarly discussion**. These are conventional descriptions; details vary by school.

## 2. What each system actually does

### BaZi (子平術): analysing chart structure

```
Four pillars → assess day-master strength → determine pattern → choose useful god → read luck cycles
```

**Nature**: a **structural analysis** method.
It answers: "what is the structure of this chart, and which elements help or harm it?"

**Output**: prose. Two practitioners may reach different conclusions on the same chart
(because useful-god selection is disputed).

### Zi Wei Dou Shu: star placements in palaces

```
Four pillars → fix life/body palaces → lay out 12 palaces → place stars → read transformations
```

**Nature**: a **symbolic star-chart** system.
It answers: "which symbolic stars fall in which life domains?"

**Output**: a chart plus palace-by-palace interpretation. Visually the most intuitive.

### Tieban Shenshu: number-to-verse lookup

```
Four pillars → derive number → kaoke calibration → verse ID → look up verse
```

**Nature**: a **numbered index** system.
It answers: "which IDs correspond to this chart, and what do those verses say?"

**Output**: numbered rhymed verses. **Not an analysis process — a direct conclusion.**

## 3. The biggest difference: is there intermediate reasoning?

This is the key to understanding all three.

```
BaZi:
  Pillars → (Ten Gods / pattern / useful god) → conclusion
            ↑ a whole reasoning chain, open to debate

Zi Wei:
  Pillars → (palaces / stars / transformations) → conclusion
            ↑ also a reasoning chain, open to debate

Tieban Shenshu:
  Pillars → (derive number → verse ID) → verse text
            ↑ this segment is a LOOKUP, not reasoning
```

**What this means**:

- BaZi conclusions **can be argued** ("you chose the wrong useful god")
- Tieban Shenshu verses **cannot be argued** (the verse says what it says; you accept it or not)

**This is a fundamental methodological difference, not a ranking of quality.**

## 4. Can they explain each other? (important)

### Common mistakes

```
❌ Using BaZi's "Seven Killings pattern" to explain a Tieban Shenshu verse
❌ Inferring which Tieban verse will appear from a Zi Wei "Seven Killings in the Life Palace"
❌ Combining all three conclusions into a "comprehensive judgement"
```

**Why this is wrong**: the three systems have completely different intermediate products.
There is no mapping. Forcing one produces whatever you wanted to see (confirmation bias).

### Correct approach

```
✅ Compute with each system separately, then read them **separately**
✅ If all three agree → noteworthy (but still not proof)
✅ If they disagree → at least one system does not "read" this chart
```

### Our stated position

> **Explaining Tieban Shenshu through BaZi theory is a category error.**
> This is already stated in the [Overview](index.md).

## 5. Which one is more accurate?

The question everyone wants answered.

**Honest answer: none of the three can be verified.**

| System | Scientific evidence | Could a controlled study be designed? |
|---|---|---|
| BaZi | None | Theoretically yes; practically almost nobody does |
| Zi Wei Dou Shu | None | Same |
| Tieban Shenshu | None | Harder (kaoke uses known facts) |

### Why the question itself is ill-posed

There is **no agreed standard** for "accurate":

- What counts as a hit? One major event, or ten minor ones?
- Who judges? The subject? A third party?
- Over what time horizon? A month? A year?

**Without a standard, comparison is impossible.**

If someone tells you "Tieban Shenshu is three times more accurate than BaZi," ask:
**How was that factor of three measured? What sample size? Who evaluated?**

See [Is it accurate?](accuracy.md).

## 6. Why do so many systems exist?

This is a **cultural history** question, and more interesting than "which is accurate."

### Reason 1: Different entry angles

- BaZi: through **five-element interactions**
- Zi Wei: through **astral symbolism**
- Tieban: through **numerical indexing**

Ancient practitioners tried different paths to the same question.

### Reason 2: Different technological conditions

- BaZi matured in Tang-Song (advanced calendrical systems)
- Zi Wei is traditionally traced to Song (astrological influence)
- Tieban arose in the Qing (printing made verse compilations feasible)

### Reason 3: Different social needs

- BaZi → suited to **discourse** (detailed, good for consultation)
- Zi Wei → suited to **diagrams** (intuitive, good for teaching)
- Tieban → suited to **authoritative assertion** ("iron-plate nailed down", builds authority)

**The idiom "铁板钉钉" (nailed on an iron plate) is itself the selling point** —
it implies unquestionability.

This is also why Tieban Shenshu is particularly easy to misuse in **high-pressure sales**
("your fate is fixed this way, you must resolve it").

## 7. Which should I learn or use?

| Your purpose | Suggestion |
|---|---|
| Understand the theoretical structure | Start with **BaZi** (most literature, clearest logic) |
| Prefer visual/diagrammatic | **Zi Wei Dou Shu** (intuitive chart) |
| Interested in "definitive assertions" | Tieban (but beware of being exploited) |
| Pure cultural research | Study all three, compare their **methodologies** |
| Seeking answers to life's confusion | **None of them will deliver** (see below) |

### One reminder

> The biggest gain from studying these systems is not "being able to predict,"
> but **seeing through how others use them to persuade you.**
>
> Once you know that "kaoke works backwards from known facts,"
> you will not be stunned by "I calculated which zodiac your father is."

## 8. Common confusions

| Claim | Fact |
|---|---|
| "Tieban Shenshu is just BaZi" | ❌ Different systems; different intermediates and outputs |
| "Zi Wei is more advanced than BaZi" | ❌ Not comparable; different entry angles |
| "Tieban Shenshu includes Zi Wei" | ❌ Independent systems; no containment |
| "Learn BaZi and you can read Tieban" | ❌ Tieban's core is number derivation + corpus; BaZi does not cover it |
| "Knowing all three lets you cross-validate" | ⚠️ You may read them separately, but cannot use one to explain another |
| "Tieban is the advanced version of BaZi" | ❌ No documentary support |

---

## 9. One-line summary

> **BaZi is structural analysis, Zi Wei is astral symbolism, Tieban is numbered indexing.**
> Their entry angles, intermediates, and outputs all differ — **they cannot explain each other**.
> As for which is more accurate — **none can be verified, and the question lacks a criterion.**
> The real gain is understanding how each one *persuades*.
