# What "12,000 Clauses" Means

People searching "Tieban Shenshu 12,000 clauses" usually want three answers:

1. Is the number real?
2. What exactly are the clauses?
3. Why do some sources say 12,000 and others something else?

This page explains **how the corpus is organised and where the number comes from**.
It contains **no clause text**.

---

## The short answer

**"About twelve thousand" is a traditional figure of scale, not an exact constant.**

| Claim | Nature |
|---|---|
| "Roughly 12,000 clauses" | Traditional figure describing order of magnitude |
| Exact count | **Varies by base edition and editorial method** |
| "Every clause applies to someone" | False. The clauses are a **lookup corpus**, not per-person verdicts |

Different sources quote 11,949 / 12,000 / 12,046 / 25,000+.
**That is usually different base editions, not fabrication.**

---

## What a clause is

Tieban Shenshu output is not analysis — it is **numbered verdict text**.

```
number  →  text (classical source)  →  optional age annotation  →  source edition
```

So "12,000 clauses" describes the **size of the numbered corpus**.

It is not 12,000 destinies, not 12,000 universal statements, and it cannot exhaust
every person.

---

## Where the numbers come from

A starting number is derived from the birth time, then positioned by *ke*
(quarter-hour block) and *fen* (minute), and finally mapped to clause numbers.

| Step | Effect on the number |
|---|---|
| True solar time correction | If wrong, the hour is wrong, so is the start number, and so is every clause |
| Hour calibration | Different calibration → different clause for the same person |
| Edition mapping table | Different editions use different number spaces |

**A clause number is not an ID — it is a position looked up under a given calibration
and a given edition.**

---

## Why editions differ in count

| Source of difference | How it shows |
|---|---|
| Different base editions (Qing print / Republican lithograph / modern transcription) | Different entries and wording |
| Whether "chart-casting instructions" occupy numbers | Some editions inflate the count with instructional entries |
| Whether duplicates are merged | Some editors merge, some keep |
| Simplified/traditional and punctuation policy | The same clause has different text across editions |
| Whether appendices are counted | Some editions count collation appendices in the total |

**Our own measurement** (statement of fact only): in publicly available corpora,
the same clause number carries substantially different text across two sources even
after normalising character variants. That means **number spaces are not portable
between editions**.

## What this means in practice

### If you are researching
- Fix which base edition you use first, or numbers cannot be compared
- Cite **edition + number**, never the number alone
- Never assemble clauses across editions

### If you are using software
- Within one product the numbering is self-consistent
- After an edition change, historical readings should keep their original version
- This is precisely why serious products preserve historical snapshots

### If you are evaluating a claim
Ask whether it states: which base edition, how the count was obtained, and how the
number space is defined.

**Any claim that says "12,000 clauses" without naming an edition cannot support research use.**

---

## Common misconceptions

**"12,000 clauses = 12,000 destiny patterns."** No — it is a verdict-text corpus.

**"More clauses means more authentic."** Not necessarily; counts differ mostly by editorial policy.

**"I can search a clause number and find 'mine'."** A number without **calibration and edition** means nothing.

**"A '12,000 clauses full download' gives me the core asset."** Circulated texts are usually
partial transcriptions with no edition metadata — and even a complete text cannot locate an
individual **without hour calibration**.
