# 考刻定分是什么？

> 铁板神数有一套「按数取条」的体系，但**真正让它区别于其他术数的，是考刻定分**。
> 这一页讲清楚它是什么、为什么存在、以及边界在哪。

---

## 一、先说两个词

### 刻

中国传统把一天分为十二个时辰，每个时辰 = 2 小时。

铁板神数在此基础上进一步细分：

```
一个时辰（2 小时）
        ↓ 分为八刻
一刻 = 15 分钟
        ↓ 每刻再分十五分
一分 = 1 分钟
```

所以一个时辰 = 八刻 = 一百二十分钟。

> **证据层级：古籍原文层面**。把时辰细分为刻，传统历法与命理文献中普遍存在。
> 但「一刻 15 分钟、一时辰八刻」这一具体划分，各文献表述未必完全一致。

### 定分

在已经确定的「刻」之内，再细分为「分」，进一步锁定出生时刻。

「考刻」+「定分」合称 **考刻定分**。

---

## 二、为什么要考刻？

核心矛盾是一个**物理事实**：

> 同一时辰（2 小时内）出生的人，按传统四柱排盘，**八字完全相同**。

古代一个时辰里出生的婴儿可能有很多。他们的八字一样，但人生并不一样。

传统上的解释是：

1. 时辰太粗（2 小时），必须细分才有区分度
2. 细分之后，不同刻分对应不同条文
3. 但出生时间往往记不准（过去没有精确计时）

**于是产生了「考刻」这个做法**：不问时钟，问人生事实。

---

## 三、传统上怎么考

### 基本思路

```
先按已知出生时间起数 → 得到一个候选刻分范围
              ↓
询问若干「人生事实」（主要是六亲信息）
              ↓
在候选范围内，找出与这些事实相符的刻分
              ↓
确定「真刻」→ 取条文
```

### 传统上常用的校验锚点

| 类别 | 典型问法 | 性质 |
|---|---|---|
| 父母 | 父亲属什么？母亲属什么？ | 硬锚点（可精确核对） |
| 兄弟 | 有几个兄弟姐妹？排行第几？ | 硬锚点 |
| 配偶 | 配偶哪年生？属什么？ | 硬锚点 |
| 子女 | 有几个孩子？几男几女？ | 硬锚点 |
| 性情 | 性格如何？ | 软锚点（主观） |
| 事业 | 从事什么行业？ | 软锚点 |

**传统上认为硬锚点更可靠**，因为生肖、人数是可以精确核对的事实，而性格描述弹性较大。

> **证据层级：传统说法**。以上流程是各派共通的**框架性描述**。
> 但「用哪些锚点、如何对应、候选如何排序」各家不同，**不存在唯一公定标准**。

## 四、这一环节的争议（必须说清楚）

考刻定分是铁板神数最独特的地方，也是**最受质疑的地方**。

### 批评方的观点

> 「你先问我父亲属什么，再告诉我条文说我父亲属什么。这叫预测吗？」

这个批评**在方法论上是成立的**：

```
如果刻分是「用已知事实调出来的」
   → 那么条文与这些事实相符，是必然的，不是预言的
```

用统计学的语言：这是**用过拟合的方式提高拟合度**。

### 支持方的回应

传统上的说法是：

1. 刻分不是"随便调"，是在**有限的候选范围**内定位
2. 定位之后，条文是**整体输出**的，不是逐条定制的
3. 真正的检验在于：**定位之后，那些没有被问到的条文，是否也应验**

**这个回应在逻辑上也说得通** —— 如果考刻只用了「父母生肖」，
但定位后输出的条文还准确描述了「婚姻状况」（没被问过），那确实有信息量。

### 我们的立场

> 我们不站队，但要提醒：**判断一个系统的准确性时，必须区分「考刻之前」和「考刻之后」。**

详见 [准不准：一个诚实的分析](accuracy.md)。

## 五、为什么各流派说法不一致

如果你去查不同来源，会发现：

| 问题 | 不同来源的回答 |
|---|---|
| 一个时辰分几刻 | 多数说八刻，也有其他说法 |
| 一刻多少分钟 | 多数说 15 分钟 |
| 用什么锚点考刻 | 各派不同 |
| 刻与条文如何对应 | **各家师传，说法不一** |
| 是否需要真太阳时 | 有的要求，有的不要求 |

### 原因

1. **传承方式**：这套东西长期是**师传**，没有统一教材
2. **文献缺失**：原始文献缺乏，各本抄录有差异
3. **后人增补**：不同时代的人做了不同补充
4. **商业保密**：部分从业者有意不公开细节

**结论**：所谓「铁板神数标准算法」**并不存在一个公认版本**。

> 任何声称「我这才是唯一正统」的说法，都需要证据支撑。我们没见过这样的证据。

## 六、我们能公开什么，不能公开什么

这一节很重要，请读完。

### ✅ 可以公开（本页已公开）

- 刻、分的基本定义
- 为什么要考刻（物理层面的原因）
- 考刻的一般流程框架
- 常用锚点的**类别**
- 各派不一致这一**事实**
- 方法论上的批评与回应

### ❌ 不在公开范围

| 内容 | 原因 |
|---|---|
| 具体的六亲—刻分对应表 | 属各家师传 / 商业实现，公开会造成误导（因为没有唯一标准） |
| 起数配值表 | 同上 |
| 刻分到条文号的完整映射 | 属商业私有实现 |
| 具体条文的完整文本 | 属私有资产（当前公开示例：0 条） |

### 为什么这样划界

不是「藏着掖着」，而是**两方面原因**：

**原因一：没有唯一正确答案**

如果公开一份「对应表」，会让人以为这是标准答案。
但实际上各派不同，公开一份反而**制造了新的误导**。

**原因二：商业边界**

我们如实说明：这些是商业产品的核心，不在公开范围。
你可以不同意这个边界，但至少我们**明确告诉你边界在哪**，
而不是含糊其辞。

## 八、一句话总结

> **考刻定分**要解决的，是「同一个时辰出生的人八字一样」这个物理问题。
> 它的传统做法是用已知事实反推真刻。
> 这个做法**在方法论上有争议**，但争议本身值得研究。
> 具体的对应表**不在公开范围**，因为各派不同、且属商业实现。
