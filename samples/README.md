# 公开条文示例 / Public Samples

> ⚠️ **当前状态：0 条示例。**

这不是遗漏，是**有意的**。本文说明原因，以及将来会怎么开放。

---

## 为什么是 0 条

### 原因一：权利未核实

条文原文本身属**公有领域**（清代及以前），但：

| 对象 | 权利状态 |
|---|---|
| 清刊本 / 民国石印本的**原文文字** | 公有领域 ✅ |
| 某机构的**扫描件** | 可能受权利保护 |
| 某人的**点校、注释、排版** | 可能构成新作品 |
| 某项目的**数字化转录** | 受其自身许可约束 |

**我们要公开示例，就必须先解决"用哪一份底本"这个问题。**

目前没有完成这一步，所以**一条也不发**。

### 原因二：避免"一点点拼出全库"

如果每天发 1 条，一年就是 365 条，几年就能拼出相当规模。
这会实质性地削弱商业产品，也违背我们对完整条文库的保护承诺。

母本对此有明确规定：**累计公开上限 30 条，且必须逐条审批**。

### 原因三：没有善本，示例会误导

条文无善本定本，各抄本文字有出入。
如果随便贴一条，读者会以为"这就是标准答案"。

## 将来会怎么开放（如果开放）

### 前置条件（缺一不可）

- [ ] 确定**具体底本**（书名、版本、藏地、页码）
- [ ] 确认该底本的**权利状态**
- [ ] 完成**逐条校勘**（至少与一个其他版本对校）
- [ ] 通过**内部权利审核**
- [ ] 经 OWNER 批准

### 开放原则（若满足前置条件）

| 原则 | 说明 |
|---|---|
| 完整标注 | 每条必须注明版本、页码 |
| 区分层级 | 原文与今注分开，不得混淆 |
| 数量封顶 | 累计不超过 30 条 |
| 不构成体系 | 不按编号顺序连续摘录（避免"可推测全库"） |
| 教学目的 | 仅用于演示"条文长什么样"，不用于任何推算 |

## 目前你可以看到什么

虽然没有真实条文，你仍然可以：

### 1. 了解条文的**格式**

```bash
cd demo
python tieban_open_tools.py check 4082
```

输出说明编号如何分段（第几集、集内第几位），
但**不返回任何条文内容**。

### 2. 了解条文的**概念**

见 [术语表 · 条文](../docs/zh-hans/glossary.md#条文-tiaowen)。

### 3. 查看**虚构样例**（明确标注）

任何用于演示的虚构样例，都会**显著标注「虚构」**，
并且**不模仿真实条文的文风**（避免被误认为真）。

## 我们拒绝的做法

以下做法我们不采用，即使它们更容易做出"丰富的内容"：

| ❌ 拒绝 | 原因 |
|---|---|
| 从 CC BY-NC 项目复制 | 违反其许可 |
| 从无许可项目复制 | 违反著作权法 |
| 网上随便搜来贴上去 | 无法核实来源与质量 |
| 把虚构内容伪装成古籍 | 欺骗读者 |
| 每天发一点慢慢凑满 | 实质泄露 |
